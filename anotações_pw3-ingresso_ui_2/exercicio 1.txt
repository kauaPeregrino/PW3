1 - Copiar os arquivos da pasta 'aula_20260324/imagens' para a pasta public do projeto pw3-ingressos-ui

2 - Abrir o projeto pw3-ingressos-ui no VS-Code

3 - Em um Terminal, executar o comando `npm install` para baixar as dependências do projeto

4 - Executar a aplicação com `ng serve -o`

5 - Em outro Terninal, crie o componente footer com o comando `ng g c shared/components/footer`

6 - No arquivo footer.css, inclua:

	.app-footer {

8 - Inclua o componente footer em app.html e visualize no navegador

9 - Crie um outro componente chamado home com o comando `ng g c pages/home`

10 - No arquivo home.css, inclua:

	.homepage .card-wrapper {
	  display: flex;
	  flex-wrap: wrap;
	  justify-content: space-between;
	  row-gap: 16px;
	  margin-bottom: 40px;
	}
	
	.homepage h2 {
	  font-size: 32px;
	}

11 - No arquivo home.html, substitua o conteúdo por:

	<section class="homepage">
	  <h2>BANNER 1</h2>
	  <h2>EM CARTAZ</h2>
	  <h2>BANNER 2</h2>
	</section>

12 - Inclua o componente home em app.html como a seguir:

	<app-header></app-header>
	<div class="main-content">
	  <app-home></app-home>
	</div>
	<app-footer></app-footer>
